# look-dev renders

blender cycles renders of the real ABYSS assets and textures, made with `Tools/blender/lookdev.py`.

**these are not screenshots of the app.** they're for judging the art. differences from the headset:
- blender uses volumetric water here, the quest build uses fog (cheaper, flatter, no light shafts)
- no fish / particles / caustics in these
- shadows are off here to match the quest build, which has no realtime shadows

don't show these to a client as "the app". show them as "art direction".
