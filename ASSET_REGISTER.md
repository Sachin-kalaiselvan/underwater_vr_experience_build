# Asset register

Everything in ABYSS is either made in this repo or comes from Unity's own packages. No marketplace models, no stock audio, no fonts outside what ships with Unity.

Status key: **first pass** = made, exported, imported cleanly, but not final art yet. **final** = signed off. Nothing is final yet.

## 3D models

All built from code in Blender 4.5.17 LTS (headless) by `Tools/blender/build_assets.py`. Colour + ambient occlusion are baked into vertex colours, so most of the world needs zero textures. Re-run the script to regenerate everything.

Honest notes from looking at the preview renders (`Tools/blender/preview_assets.py` makes them):
- good enough to keep building on: terrain, rocks, brain coral, staghorn, table coral, sea fan, sponge, seagrass, tube worms, basalt columns, wreck hull, bell
- need another pass before any client sees them: info marker (reads as a pot), ray (flat plate, odd tail), anchor (flukes look like chain links), fish tail, giant clam (too flat), mast (too thin), arch (lumpy tube)
- none have LODs yet. biggest single mesh is the terrain at 26k tris

## Shaders

All hand-written HLSL for URP, in `Assets/ABYSS/Art/Shaders`. Not compiled yet (needs the Unity editor).

| Shader | Used for |
|---|---|
| ABYSS/UnderwaterVertexLit | almost all world geometry. vertex colour, main light + caustic cookie, ambient SH, fog, optional bioluminescent glow, optional two-sided |
| ABYSS/HighlightRim | hover glow on interactables |
| ABYSS/MarkerBeam | soft light beam over activity destinations |
| ABYSS/MarineSnow | drifting particles |
| ABYSS/FadeOverlay | fades between locations |

## Audio

All synthesised from scratch by `Tools/audio/make_audio.py` (numpy, no samples). 44.1 kHz mono wav, Unity compresses to Vorbis on import.

| Clip | Length | Use |
|---|---|---|
| amb_underwater_loop | 30 s loop | ambience |
| amb_bubbles_loop | 20 s loop | ambience |
| ui_hover, ui_click, ui_menu_open | <0.4 s | menus |
| int_select, int_fail, int_discover | <1 s | interaction feedback |
| int_step_complete, int_activity_complete | <2 s | activities |
| nav_teleport | 0.5 s | fades |

Status: first pass. Functional and gentle, but a sound designer should replace the ambience before a client demo.
