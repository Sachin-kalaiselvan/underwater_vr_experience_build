# ABYSS

underwater VR exhibition for Meta Quest. Unity 6.3 LTS, URP, OpenXR, XRI 3.

start here: [PROJECT_DOCUMENTATION.md](PROJECT_DOCUMENTATION.md). to build: [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md).

quick version: open in Unity 6000.3.29f1, run `ABYSS > 1` (twice on a fresh clone), then `ABYSS > 2`, then `ABYSS > 4` for the apk.

there's also a browser / webxr version of the same world in [web/](web/README.md), deployable on vercel.
